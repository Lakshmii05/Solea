# SOLEA - Shoe Store Android App

SOLEA is a beginner-friendly shoe store Android application built using **Java** and **Android Studio**.

## Features

* SOLEA shoe store home screen
* Black, white, and orange theme
* "Step into your style" heading
* Search shoes field
* Shoe categories:

  * Men
  * Women
  * Running
* Popular Products section
* Horizontal scrolling product cards
* Shoe product images
* Product names and prices
* Vertical scrolling for the home screen

## Current Products

The home screen currently displays:

* Men's Sports Shoe — ₹1,499
* Men's Casual Shoe — ₹1,299
* Men's Running Shoe — ₹1,799
